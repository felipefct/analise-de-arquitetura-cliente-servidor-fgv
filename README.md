# Meu Ambiente Frontend

Este é um ambiente configurado para desenvolvimento frontend utilizando Node.js e NPM.

## Como instalar as dependências
Após clonar ou baixar este projeto, abra o terminal na pasta raiz e execute o comando:
`npm install`

## Como executar cada script
- `npm start`: Inicia a aplicação utilizando o Node (ambiente de produção).
- `npm run dev`: Inicia a aplicação para desenvolvimento.
- `npm run lint`: Executa o ESLint para analisar o código e encontrar problemas de sintaxe ou estilo.
- `npm run format`: Executa o Prettier para formatar automaticamente todos os arquivos suportados no projeto.

## Propósito de cada ferramenta utilizada
- **Express**: Framework rápido e minimalista para Node.js, utilizado para criar o servidor e APIs.
- **ESLint**: Ferramenta de linting (análise estática) que ajuda a manter a qualidade e padronização do código JavaScript.
